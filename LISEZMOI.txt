# Sutom des widrine — dossier `public/` (déployable)

Ce dossier est le **répertoire de déploiement unique** pour un serveur intranet d'entreprise.
Il contient le jeu complet, prêt à déposer sur le serveur.

## Ce que contient

- `index.html` — page d'accueil du jeu
- `jeu.css` — styles
- `classement.html` — classement des joueurs (mot de passe embarqué)
- `manifest.json` — manifeste PWA
- `js/` — 23 fichiers JS (compilés depuis TypeScript, ils incluent :
  - `require.js` — loader AMD,
  - `main.js` — point d'entrée AMD,
  - `gistDatabase.js` — module AMD pur (parle directement à GitHub),
  - `gistLeaderboard.js`, `dictionnaire.js`, `grille.js`, `input.js`,
  - `gestionnaire.js`, `panelManager.js`, `sauvegardeur.js`, `configurationPanel.js`,
  - `audioPanel.js`, `themeManager.js`, `instanceConfiguration.js`,
  - `statistiquesDisplayer.js`, `tempsHelper.js`, `finDePartiePanel.js`,
  - `notificationMessage.js`, `copieHelper.js`, `entites/*.js`)
- `fonts/` — Roboto Regular, RobotoMono Regular
- `sons/` — sons audio (lettre non trouvée, mal placée, bien placée)
- `icone-192.png`, `icone-512.png`, `apple-touch-icon.png`, `favicon.ico`, `favicon.svg`
- `prenomsFeminins.txt` — liste des prénoms féminins (déclencheur de la liste)
- `LISEZMOI.txt` — cette documentation

## Déploiement

Depuis un serveur statique (Apache, Nginx, etc.) :

```bash
cd public
cp -r . /var/www/html/sutom/
```

Les fichiers `js/server.js`, `js/gistDatabase.statique.js` (fichiers de dev) sont
**supprimés de la version déploiée** (ce dossier contient uniquement les fichiers
du jeu, sans infrastructure de développement).

## Sécurité

- Le token GitHub et le mot de passe du classement sont embarqués dans `js/gistDatabase.js`
  et `classement.html`.
- ⚠️ Ne jamais déployer ce dossier sur un **site public** — le token est en clair dans
  la console du navigateur.
- Pour un usage public, utiliser la variante `public/serveur/` (Node.js + Express,
  token côté serveur).

## Fichiers à ne pas mettre sur le serveur (résidus)

- `public/deployable/` — version de déploiement (ne pas déployer)
- `public/serveur/`, `public/statique/` — variantes de déploiement (déjà supprimées)
- `public/prenomsFeminins.txt` — non référencé par le JS (déjà dans dictionnaire.js)
- `public/mots/index.html` — fichier vide (fichier de garde, supprimé par `.gitignore`)
